用 Python 调用 AWS DevOps Agent：一页上手

用代码向 Agent 提问、发起故障调查、读取调查过程和建议。适合接入告警、工单和日报流程。

① 准备（一次性）

  1. 建好 Agent Space，并关联要监控的 AWS 账号（控制台、CLI、CDK、CloudFormation、Terraform 都可以）。记下 agentSpaceId。
  2. Region：Agent Space 要建在支持的 15 个 Region 之一（如 us-east-1、eu-central-1、ap-northeast-1）。它能调查账号内所有 Region 的资源，不用每个 Region 建一个。
  3. SDK：Python 3.10+，pip install -U boto3（≥ 1.43），客户端名是 devops-agent。
  4. 调用方 IAM 权限（本页代码用到的最小集合）：
{ "Effect": "Allow", "Resource": "*",
  "Action": [ "aidevops:CreateChat", "aidevops:SendMessage",
    "aidevops:CreateBacklogTask", "aidevops:GetBacklogTask",
    "aidevops:ListExecutions", "aidevops:ListJournalRecords",
    "aidevops:ListRecommendations" ] }

② 两种用法

问答（Chat）调查（Investigation）
适合查资源、查告警、出报告故障根因分析
接口create_chat + send_messagecreate_backlog_task
返回流式文本，秒级异步任务，要轮询，分钟级
并发默认值10 / Space3 / Space（可申请提高）

调查的调用顺序：

create_backlog_task→get_backlog_task 轮询→ list_executions→list_journal_records→list_recommendations

任务结束状态：COMPLETED FAILED TIMED_OUT CANCELED，还有 LINKED（合并到已有调查）、SKIPPED（被 triage 跳过）。

③ 代码

import boto3, time
c = boto3.client("devops-agent", region_name="us-east-1")
SPACE = "<AGENT_SPACE_ID>"

# A. 问答：流式打印回答
def ask(q):
    ex = c.create_chat(agentSpaceId=SPACE)["executionId"]
    r = c.send_message(agentSpaceId=SPACE,
                       executionId=ex, content=q)
    for e in r["events"]:
        d = e.get("contentBlockDelta", {}).get("delta", {})
        if "textDelta" in d:
            print(d["textDelta"]["text"], end="")

ask("过去 24 小时有哪些告警触发了？")
# B. 调查：发起 → 等待 → 读过程和建议
END = ("COMPLETED", "FAILED", "TIMED_OUT", "CANCELED", "LINKED",
       "SKIPPED")

def investigate(title, desc):
    kw = dict(agentSpaceId=SPACE)
    t = c.create_backlog_task(**kw, title=title,
          description=desc, taskType="INVESTIGATION",
          priority="HIGH")["task"]
    tid = t["taskId"]
    while t["status"] not in END:
        time.sleep(30)
        t = c.get_backlog_task(**kw, taskId=tid)["task"]

    exs = c.list_executions(**kw, taskId=tid)
    for ex in exs["executions"]:      # Agent 每一步
        rs = c.list_journal_records(**kw, order="ASC",
                 executionId=ex["executionId"])
        for r in rs["records"]:
            print(r["recordType"], r["content"])

    recs = c.list_recommendations(**kw, taskId=tid)
    for rec in recs["recommendations"]:  # 建议
        print(rec["title"], rec["content"]["summary"])

investigate("结账 API 5xx 升高", "14:05 UTC 起 ALB 5xx 超过 5%")

④ 常见接法

  • 告警自动调查：CloudWatch 告警 → EventBridge → Lambda 调 create_backlog_task，把告警名、时间、指标写进 description。
  • 写回工单或群：调查结束后，把 list_recommendations 的结果发到工单系统或 IM。也可以直接用官方的 ServiceNow、PagerDuty、Slack、Teams 集成。
  • 日报：定时调用 ask("生成过去 24 小时的运维健康摘要")。
  • 不写代码的替代：Webhook、MCP server、A2A 也能触发 Agent，见官方文档。

⑤ 注意事项

  • description 写得越具体（时间、现象、影响范围），调查越准。
  • send_message 返回事件流，要用 for 循环读，不是一次性返回 JSON。
  • 调查可能被自动合并（LINKED）到已有调查，这时去看主调查。
  • Lambda 自带的 boto3 可能太旧，没有 devops-agent 客户端，要把新版 boto3 一起打包。
  • 用量可以用 get_account_usage() 查看本月调查小时数、问答次数。
完整可运行脚本：仓库根目录的 devops_agent_quickstart.py。用法：AGENT_SPACE_ID=xxx python devops_agent_quickstart.py ask "问题" 或 ... investigate "标题" "描述"。
