用 Python 调用 AWS DevOps Agent：一页上手

用代码向 Agent 提问、发起故障调查、读取调查过程和建议。适合接入告警、工单和日报流程。

① 准备（一次性）

  1. 建好 Agent Space，并关联要监控的 AWS 账号（控制台、CLI、CDK、CloudFormation、Terraform 都可以）。记下 agentSpaceId。
  2. Region：Agent Space 要建在支持的 15 个 Region 之一（如 us-east-1、eu-central-1、ap-northeast-1）。它能调查账号内所有 Region 的资源，不用每个 Region 建一个。
  3. SDK：Python 3.10+，pip install -U boto3（≥ 1.43），客户端名是 devops-agent。
  4. 调用方 IAM 权限（本页代码用到的；Resource 可改成你的 Agent Space ARN）：
{ "Effect": "Allow", "Resource": "*",
  "Action": [ "aidevops:CreateChat", "aidevops:SendMessage",
    "aidevops:CreateBacklogTask", "aidevops:GetBacklogTask",
    "aidevops:ListExecutions", "aidevops:ListJournalRecords",
    "aidevops:ListRecommendations" ] }

② 两种用法

问答（Chat）调查（Investigation）
适合查资源、查告警、出报告故障根因分析
接口create_chat + send_messagecreate_backlog_task
返回流式文本，秒级异步任务，要轮询，分钟级
并发默认值10 / Space3 / Space（可申请提高）

任务结束状态：COMPLETED FAILED TIMED_OUT CANCELED，还有 LINKED（合并到已有调查）、SKIPPED（被 triage 跳过）。PENDING_CUSTOMER_APPROVAL 表示等你在网页里批准缓解方案。

③ 代码

import boto3, json, time
c = boto3.client("devops-agent",
                 region_name="us-east-1")
kw = dict(agentSpaceId="<AGENT_SPACE_ID>")

# A. 问答：只打印 text 块
def ask(q):
    ex = c.create_chat(**kw)["executionId"]
    r = c.send_message(**kw, content=q,
                       executionId=ex)
    k = {}                   # 块序号 -> 类型
    for e in r["events"]:
        if "contentBlockStart" in e:
            b = e["contentBlockStart"]
            k[b["index"]] = b["type"]
        d = e.get("contentBlockDelta") or {}
        if k.get(d.get("index")) == "text":
            t = d["delta"].get("textDelta", {})
            print(t.get("text", ""), end="")
    print()
# thinking、tool_summary、final_response
# 等块不是答案，跳过

ask("过去 24 小时有哪些告警？")
# B. 调查：发起 → 等待 → 翻页读结论和建议
END = ("COMPLETED", "FAILED", "TIMED_OUT", "CANCELED",
       "LINKED", "SKIPPED", "PENDING_CUSTOMER_APPROVAL")
SHOW = {"observation": "analysis", "root_cause": "description",
        "investigation_gap": "description",
        "investigation_result": "text"}

def pages(op, key, **a):                  # 自动翻页
    p = c.get_paginator(op).paginate(**kw, **a)
    return p.search(key + "[]")

def investigate(title, desc):
    t = c.create_backlog_task(**kw, title=title,
          description=desc, taskType="INVESTIGATION",
          priority="HIGH")["task"]
    tid = t["taskId"]
    while t["status"] not in END:
        time.sleep(30)
        t = c.get_backlog_task(**kw, taskId=tid)["task"]

    for ex in pages("list_executions", "executions", taskId=tid):
        eid = ex["executionId"]
        for r in pages("list_journal_records", "records",
                       executionId=eid, order="ASC"):
            field = SHOW.get(r["recordType"])
            if not field:
                continue                # 跳过给网页用的记录
            b = r["content"]            # 通常是 JSON 字符串
            b = json.loads(b) if isinstance(b, str) else b
            print(b.get("title", ""), b.get(field))
    # list_recommendations 没有 paginator，多页时用 nextToken
    recs = c.list_recommendations(**kw, taskId=tid)
    for rec in recs["recommendations"]:
        print(rec["title"], rec["content"]["summary"])

investigate("结账 API 5xx 升高", "14:05 UTC 起 5xx 超过 5%")

④ 常见接法

  • 告警自动调查：CloudWatch 告警 → EventBridge → Lambda 调 create_backlog_task，把告警名、时间、指标写进 description。
  • 写回工单或群：调查结束后，把 list_recommendations 的结果发到工单系统或 IM。也可以直接用官方的 ServiceNow、PagerDuty、Slack、Teams 集成。
  • 日报：定时调用 ask("生成过去 24 小时的运维健康摘要")。

⑤ 注意事项

  • description 写得越具体（时间、现象、影响范围），调查越准。
  • send_message 返回事件流，要用 for 循环读，不是一次性返回 JSON。
  • 调查可能被自动合并（LINKED）到已有调查，这时去看主调查。
  • Lambda 自带的 boto3 可能太旧，没有 devops-agent 客户端，要把新版 boto3 一起打包。
  • journal 每页最多 100 条，结论在最后，一定要翻页读完。
完整可运行脚本：python/devops_agent_quickstart.py（Node.js、Java 版在 nodejs/、java/）。用法：cd python; AGENT_SPACE_ID=xxx python devops_agent_quickstart.py ask "问题" 或 ... investigate "标题" "描述"。
